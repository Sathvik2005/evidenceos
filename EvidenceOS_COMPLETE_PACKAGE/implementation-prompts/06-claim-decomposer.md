# Prompt 06 — Claim Decomposer Agent

## Objective

Implement the Claim Decomposer Agent.

Input: an investigation question.
Output: atomic, non-overlapping, researchable claims.

Requirements:
1. Use a strict structured output schema.
2. Validate claims deterministically.
3. Do not research sources.
4. Do not assign evidence states.
5. Do not invent factual conclusions.
6. Retry only within the configured bound.
7. Preserve traceability to the originating investigation.
8. Add unit, contract, and golden tests.

Include cases for atomic decomposition, ambiguous questions, and over-broad claims.
