# Prompt 13 — Frontend Foundation

## Objective

Establish the EvidenceOS frontend foundation.

Use React + Vite + TypeScript + Tailwind/shadcn conventions already selected by the project.

Tasks:
1. Establish routing and application shell.
2. Create accessible design tokens.
3. Implement the visual direction from UI_SPEC.md: warm ivory/parchment light mode, dark observatory mode, editorial typography, generous whitespace, restrained motion.
4. Establish reusable components.
5. Connect the frontend to real backend contracts.
6. Do not create fake data or fake AI behavior.
7. Add loading, empty, error, and partial-state primitives.

Do not implement all product screens yet.
