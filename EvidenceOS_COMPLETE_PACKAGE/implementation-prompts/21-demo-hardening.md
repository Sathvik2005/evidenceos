# Prompt 21 — Demo Hardening

## Objective

Harden the 3–5 minute EvidenceOS demo.

Use the documented demo question:
“Does remote learning improve student outcomes?”

The demo must visibly demonstrate:
1. question
2. claims
3. evidence
4. contradiction
5. claim detail
6. new evidence
7. state transition
8. history
9. architecture/trust model

The signature transition is:
PARTIALLY SUPPORTED → NEW EVIDENCE → CONFLICTING

Requirements:
1. No fake UI behavior.
2. No hidden manual database edits during the demo.
3. No fabricated citations.
4. Ensure the demo path is deterministic enough to rehearse.
5. Add a concise demo checklist and recovery procedure.
