# Prompt 10 — Evaluator Agent

## Objective

Implement the Evaluator Agent as an audit layer.

Evaluate:
- Evidence Quality
- Grounding
- Contradiction Handling
- State Justification
- Uncertainty Handling

Score each dimension 0–2 internally according to EVALUATION.md, but do not present the score as a political or external quality ranking; this is an internal software evaluation rubric.

Requirements:
1. Audit the analyst output.
2. Do not silently rewrite evidence.
3. Do not invent evidence.
4. Identify critical failures.
5. Produce structured findings and a validity decision.
6. Integrate deterministic hard-rule results.
7. Add golden regression cases.
