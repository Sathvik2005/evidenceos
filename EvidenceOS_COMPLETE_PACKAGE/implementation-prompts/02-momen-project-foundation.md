# Prompt 02 — Momen Project Foundation

## Objective

Establish the Momen backend foundation for EvidenceOS.

Read CONTEXT.md, ARCHITECTURE.md, DATA_MODEL.md, BUILD_PLAN.md, RULES.md, CLAUDE.md, and the Momen documentation available in the project.

Tasks:
1. Inspect the current Momen project/workspace before modifying it.
2. Establish the backend project structure and environment configuration.
3. Configure the Momen integration required by the application.
4. Establish the frontend/backend boundary.
5. Configure development and environment variables without exposing secrets.
6. Verify backend synchronization and logs.
7. Document the Momen setup and local development path.

Do not implement the full database schema, agents, LangGraph workflow, or product UI yet.

Verify the foundation with the available Momen preview/sync path and local checks. Do not proceed to Prompt 03 automatically.
