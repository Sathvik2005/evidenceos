# Prompt 20 — Deployment

## Objective

Prepare EvidenceOS for production deployment.

Tasks:
1. Establish production environment configuration.
2. Configure secrets securely.
3. Configure database/backend/frontend deployment.
4. Configure logging and health checks.
5. Verify migrations/synchronization.
6. Verify CORS and API boundaries.
7. Configure the public application URL.
8. Document rollback/recovery.
9. Run production-like smoke tests.

Do not hardcode credentials or environment-specific secrets.
